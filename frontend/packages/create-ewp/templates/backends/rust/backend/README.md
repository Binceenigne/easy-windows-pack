# Rust native host

Use `--titlebar-mode default|minimal|native` (or EWP_TITLEBAR_MODE) to choose initial chrome. Default/minimal are frameless; native creates a real system caption. Crossing that boundary through the bridge requests a restart with the selected mode.

Windows, Rust/Cargo with the x86_64-pc-windows-msvc target, Visual Studio Build Tools + Windows SDK, and Microsoft Edge WebView2 Runtime are required. From the generated project root run `cargo build --manifest-path backend/Cargo.toml --release`; output is backend/target/release/ewp-host.exe unless CARGO_TARGET_DIR is set. `cargo test --manifest-path backend/Cargo.toml --release` verifies the bridge and navigation/path policy. The native libraries are official Wry 0.53.5 and tao 0.34.5, pinned in Cargo.toml. Cargo resolves their transitive crates; keep the resulting Cargo.lock for reproducible application builds. Consult each dependency's supplied MIT/Apache license notices for redistribution.

Arguments: `--url <http(s) loopback URL>` OR `--assets <frontend directory containing index.html>`, optionally `--title <text>`, `--debug`, `--help`. Environment equivalents: EWP_DEV_URL, EWP_ASSETS, EWP_APP_TITLE, EWP_DEBUG=1. Explicit URL/assets flags override the opposite inherited value; both flags together are rejected. With neither, look beside the executable for frontend/index.html, then the source project's output/frontend/index.html. Explicit relative asset paths use the caller's cwd. Errors exit nonzero. WebView2 profiles live in a per-executable LOCALAPPDATA directory.

Production uses a controlled HTTPS resource protocol at https://ewp.local/index.html; Wry translates requests to ewp://local/... internally. ES module MIME types are supplied explicitly. Paths are decoded, validated, canonicalized and confined to the selected local directory; symlinks/junctions and Windows alternate data streams are rejected. File-to-file browser access is not enabled. Only the index document (query/hash allowed) is trusted; development uses the exact selected loopback origin. Frame navigation, popups, downloads and browser permissions are denied before application HTML loads. Native IPC also verifies WebView2's source URI, current document and navigation generation.

Bridge: ewpNative.call(method,argsArray), plus the fixed pywebview.api adapter for the shared frame. Methods: get_window_state/get_window_size, window_action(minimize/maximize/restore/close), native_drag(move or eight edge/corner directions), get/set/toggle_always_on_top, set_window_size(width,height), hide_window/show_window, set_titlebar_mode(default/minimal/native). Sizes are integer physical client pixels, width 320..16384 and height 200..16384; restore before resizing. Application errors return {ok:false,error}; transport failures reject. Requests are bounded and replies are associated with their original document. Native titlebar requests return titleBarMode:native, restartRequired:true, activeTitleBarMode unchanged; the launcher owns restart/configuration. This host starts frameless.

tao supplies the Windows move/resize and maximize implementation, including monitor work-area bounds. Real mouse drag, maximize drag-restore and Windows snap require an interactive desktop for acceptance testing. The framework tests/native-backends-* scripts build isolated copies and exercise the real WebView2/HWND host.
