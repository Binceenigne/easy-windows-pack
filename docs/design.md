# 应用 UI 规则

供使用 easy-windows-pack 开发应用的人填写真实产品的视觉与交互约定。当前 welcome 是示例，应用规则尚待确定。

- 目标用户与主要任务：待用户填写。
- 主题、品牌与信息密度：待用户填写；可参考现有 welcome 后按产品需要调整。
- 页面流程与关键反馈：待用户填写，例如提交失败如何保留输入、恢复操作。
- 设计稿或样式来源：有实际内容时补充链接。

只维护应用需要的少量规则，无需组件数量盘点或完整框架规范。示例的配色、品牌和布局可替换；窗口外观的可选配置见 [窗口指南](window-styles.md)，业务入口见 [index.md](index.md)。框架内部的架构、构建和接口说明保留在 [文档导航](README.md) 的对应专题。
